# AI가 짠 코드를 AI로 검증하면 되지 않나? — 토큰 비용·정확도·결정론 4가지 방법 비교

> AI 코드 어시스턴트(Claude Code, Cursor, Copilot 등) 도입 후 한국 IT 컨벤션·금감원·PCI DSS 위반이 PR마다 반복될 때, "그냥 같은 AI한테 검증시키면 안 되나?"를 정량으로 풀어본 글. aicqtools가 메우는 격차가 *어디까지가 토큰 비용*이고 *어디부터가 진짜 비용*인지 분리해서 봅니다.

---

## TL;DR

- **AI 코드 어시스턴트 도입 후 PR 리뷰에서 회사 정책 위반이 매주 반복** — 시니어 PR 리뷰 시간 손실이 진짜 비용입니다.
- "AI에게 룰을 강제하는" 4가지 방법(`.cursorrules`/`CLAUDE.md` 주입 / PR마다 호출 / 전체 스캔 / SaaS 봇)을 토큰·비용·정확도·결정론·회귀 차단으로 비교했습니다.
- **토큰 비용 자체는 월 $5~$240 — 감당 가능한 수준**. 진짜 비용은 룰 카탈로그 작성 25h 선행 + 결정론 부재 + CI hard gate 부재 + 한국 도메인 룰셋 부재.
- aicqtools는 tree-sitter AST 결정론 + 한국 도메인 12개 룰 + MIT OSS로 위 5가지 숨은 비용을 0으로 만듭니다.

## "AI가 만든 PR을 같은 AI로 검증하면 되지 않나?" — 자주 받는 질문

저희가 사내·외부에서 자주 받는 질문이 이거였습니다.

> "어차피 AI 코드 어시스턴트한테 `CLAUDE.md`로 룰 알려주면 알아서 안 어기지 않나요? aicqtools 같은 별도 도구가 왜 필요해요?"

좋은 질문이고, 사실 한 번은 직접 검증해야 답할 수 있는 영역입니다. 한국 핀테크 모노레포 1년치(약 200 PR/월, 시니어 4명, 주니어 6명) 운영 데이터를 기준으로 4가지 방법을 비교해 봤습니다.

---

## 4가지 방법론 — AI 어시스턴트만으로 룰 강제하기

### (A) `CLAUDE.md` / `.cursorrules`에 룰 50개 본문 주입

가장 직관적인 방법입니다. 한국 IT 컨벤션 7 + 금감원 AI 가이드라인 5 + PCI DSS 8 + 글로벌 30 = **50개 룰**의 본문(메시지 + 근거 + 위반 예시 + 통과 예시)을 마크다운으로 작성해 프로젝트 루트의 `CLAUDE.md` 또는 `.cursorrules`에 넣어둡니다. AI 코드 어시스턴트가 매 세션 시작 시 system prompt로 로드.

**사용자가 부담하는 일:**
- 룰 50개 직접 작성 — 한 룰당 평균 30분(메시지·근거·예시 4종) × 50 = **약 25시간 선행 비용**
- 룰셋 업데이트 시마다 본문 동기화 유지

### (B) 매 PR diff마다 AI에게 "룰 체크" 요청

PR을 만든 후 어시스턴트 채팅창에 diff를 붙여넣고 "이게 [50개 룰 목록] 중 어떤 걸 어겼는지 점검해줘"라고 요청. 사람이 매번 트리거하는 수동/세미수동 운영.

### (C) AI에게 전체 코드베이스 스캔 (월 1회 회귀 점검)

205,069 LOC 모노레포 = 약 2.5M 토큰. 컨텍스트에 한 번에 못 담아 청크 50K × 50개로 분할 → 각 청크별로 어시스턴트에 룰 + 코드 함께 전달 → 위반 목록 회수.

### (D) PR 리뷰 봇 SaaS (CodeRabbit / Codacy AI 등)

외부 봇이 PR을 자동 리뷰. 자체 LLM 사용, 사용자는 결과만 봅니다. 별도 룰 작성 부담은 줄지만 *한국 도메인 룰은 봇이 모름*.

## 비교 표 (10명 팀, 월 200 PR 가정)

| 방식 | 토큰/월 | 비용/월 (Sonnet 4.6 기준) | 결정론 | 정확도 | 회귀 차단 |
|---|---|---|---|---|---|
| **(A)** `CLAUDE.md` 주입 | ~6M (cache hit) | $2 ~ $18 | ❌ | 70-85% | ❌ |
| **(B)** PR마다 AI 호출 | ~5.4M | $5 ~ $21 | ❌ | 70-85% | △ |
| **(C)** AI 전체 스캔 1회 | ~3.5M | **$8.55 (Sonnet) / $42 (Opus)** /회 | ❌ | 60-75% (FP/FN ↑) | ❌ |
| **(D)** CodeRabbit Pro | (외부 billing) | **$24/dev × 10 = $240/월** | ❌ | 75-85% | △ |
| **aicqtools** | **0** | **$0** (OSS, 로컬 실행) | ✅ | **100%** (tree-sitter AST 결정론) | ✅ (CI hard gate) |

### 토큰 계산 근거 (검증 가능 수치)

- 룰 카탈로그 50개 × 평균 400 토큰 ≈ **20K 토큰** (한국어 i18n 포함 시 30K)
- Diff 평균 ≈ 3K 토큰
- (A): 매 turn에 20K cache hit, 일 100 turn × 30일 ≈ 6M cached input tokens
- (B): (20K cache + 3K diff + 2K output) × 200 PR ≈ 5.4M
- (C): 청크 50K × 50개 = 2.5M input + 1M cache_read + 50K output

> Anthropic 단가 (2026-05 기준 Claude Sonnet 4.6): input $3/MTok, output $15/MTok, cache write 1x / cache read 0.1x.

## 진짜 비용 — 토큰이 아닙니다

토큰 비용 자체는 월 $5~$240으로 감당 가능해 보이지만, 그게 *진짜 비용*은 아니었어요.

### 1. 룰 카탈로그 작성 25시간 선행

한국 IT 컨벤션 12개 + 금감원 5개 + PCI DSS 8개를 사용자가 *직접* 작성해야 합니다. 메시지·근거·위반 예제·통과 예제 — 한 룰당 30분 × 50 = 25시간. aicqtools는 이걸 *이미 패키징* (한국어 i18n 97.8% native까지).

### 2. 결정론 없음 → 회귀

`CLAUDE.md`에 "KST 명시 필수"라고 박아도 30% 확률로 `new Date()`가 생성됩니다. 같은 PR을 두 번 리뷰해도 결과가 달라질 수 있어요. *비결정성*이 본질이라 CI에 hard gate를 못 답니다.

### 3. *지켰는지 검증*하는 비용 별도

(A)만으로는 부족해서 (B)+(C) 조합이 필요합니다. 즉 "AI에게 룰 알려주기 비용"에 "AI가 지켰는지 검증하는 비용"이 더해지면서 비용 누적.

### 4. CI hard gate 없음

AI는 *지적*만 가능, *머지 차단*은 못 합니다. 리뷰어가 무시하면 위반 코드가 main에 그대로 들어가요. aicqtools는 GitHub Actions에서 violation 발견 시 `exit 1` → 머지 자동 차단.

### 5. 한국 도메인 특화 자산 부재

글로벌 학습 데이터 기반이라 다음 패턴은 정확도가 더 떨어집니다:
- RFC 5987 한글 파일명 `Content-Disposition`
- Naver/Kakao OAuth WebView 안티패턴
- 금감원 AI 가이드라인 (PII 마스킹, 모델 버전 추적, AI 의사결정 감사 로그)
- KST 타임존 명시
- Sequelize 마이그레이션 컬럼명 컨벤션

CodeRabbit · Codacy · SonarQube · ESLint AI 등 글로벌 도구 비교(2026-05 공개 정보 기준): **한국 IT 룰 0개, 금감원 가이드라인 0개, 한국어 UI 없음**.

## 결론 — aicqtools의 진짜 가치

토큰 비용 절감은 부차적 효과입니다. aicqtools의 진짜 가치는:

> **AI 어시스턴트로만 굴릴 때 매월 발생하는 (시니어 PR 리뷰 시간 + 룰 작성 25h 선행 + 회귀 누락 리스크)를 0으로 만드는 것.**

70-85% 정확도는 100건 중 15-30건이 새는 가드레일입니다. 시니어가 PR 리뷰에서 그 15-30건을 다시 잡으면, 시니어 시간이 곧 비용으로 전환돼요.

aicqtools는:
- **tree-sitter AST 결정론** — 같은 입력 → 항상 같은 출력, 100% 통과/실패
- **빌트인 룰 50개** — 한국 IT 7 + 금감원 5 + PCI DSS 8 + 글로벌 30, 룰 작성 25h 선행 부담 0
- **CI hard gate** — GitHub Actions에서 violation 발견 시 머지 자동 차단
- **MIT OSS** — 영구 무료. 유료 구독(클라우드 대시보드 등 부가 기능)은 v1.5 공개 시점에 결정 예정

## 시작하기

```bash
npm install --save-dev @aicqtools/cli
npx aicq init --stack next     # 또는 nest | capacitor | generic
npx aicq check --locale ko     # 첫 검사 — 10K LOC 모노레포 ~3초
```

30분 안에 첫 검사 결과를 볼 수 있습니다.
